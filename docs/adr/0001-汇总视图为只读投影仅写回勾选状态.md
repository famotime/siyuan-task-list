# 汇总视图为原文档的只读投影，仅写回勾选状态

---
status: accepted
date: 2026-11-01
---

「按完成状态重排序」被限定为**仅显示重排**：同一列表块内的任务在汇总视图中未完成在前、已完成在后，但原文档中列表项的真实先后（源顺序）永不改写。汇总视图对原文档唯一的写操作是勾选状态的切换（走内核专用 API `updateTaskListItemMarker`，只改任务标记节点、不动块子树）。

## Considered Options

- **同时改写原文档块顺序**（技术上可行，内核有 `moveBlock` API）：被否决。用户在视图中按状态排序是"查看诉求"，而原文档顺序承载写作结构；自动搬移列表项会造成破坏性变更，且与"视图是原文档投影"的定位冲突。

## Consequences

- 视图中相邻展示的任务，在原文档中可能不相邻（不同列表块被状态排序打散仅发生在同一列表块分组内，跨分组不合并）。
- 写回勾选必须用 `updateTaskListItemMarker`/`batchUpdateTaskListItemMarker`，不得用 `updateBlock` 传 markdown——后者是整子树替换，会丢失任务项下挂的嵌套子列表。
